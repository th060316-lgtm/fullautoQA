# FullAutoQA v0.3.3 完全保存版の取得・結合

このフォルダは、Runtime／Payloadを含む保存済みCandidate一式を、GitHubで受け渡すための分割セットです。Sourceだけの配布ではありません。ファイル一式の完全性と、製品のQA受入合格は別です。製品受入はHOLDで、実ゲームの3周E2E合格を示す配布ではありません。

1. GitHubの「Code → Download ZIP」でリポジトリ全体を取得するか、cloneします。
2. Download ZIPの場合は、まず全体を展開してください。ZIP内から直接実行しないでください。
3. `開発版/complete_v033/JOIN_COMPLETE.cmd`を一度起動します。
4. `JOIN COMPLETE`が表示されたら、同じフォルダにできた`FullAutoQA_v0.3.3_CANDIDATE.zip`を展開します。
5. 展開先の`START_QA.cmd`を起動します。実ゲームのQAには、そのゲームのProfile／QA Target設定が必要です。同梱Fixtureの自己診断と実ゲームのQAは別です。

結合時の追加ソフト導入、ネット接続、管理者権限は不要です。Windows標準のPowerShell 5.1を使います。結合先には、分割ファイルとは別に約1.10GBの空き容量が必要です。Candidate展開後の容量はさらに必要です。

## 自動検査

`manifest.json`の順番どおりに全128ブロックを調べ、各ファイルの存在・サイズ・SHA-256を検査します。一時ファイルへ結合後、全体サイズとSHA-256が一致した場合だけ完成ファイル名へ変更します。

- 完成ZIPのサイズ: **1,099,679,545 bytes**
- SHA-256: `8858cd388d283a294e13ed3e9d9e87e930b26d84bd83fe548dba10883007816c`

同じ完成ZIPが既にあれば、ハッシュ一致を確認して再利用します。異なる同名ファイルがあれば上書きせず停止します。ブロック不足・破損時は停止し、未完成の一時ファイルを除去します。分割ファイルの名前変更・移動・一部だけの取得は避けてください。

結合スクリプトは全体SHA-256によるバイト同一性を確認します。Windows上でZIPの全Entry CRCを検査したと報告するものではありません。ZIP全EntryのCRC検査は、制作側のPython検証記録で別に扱います。今回の結合スクリプト自体のWindows実行も、別途確認が必要です。

`JOIN COMPLETE`は結合・完全性検証の完了表示です。ゲームのQA完了や製品受入合格を意味しません。
