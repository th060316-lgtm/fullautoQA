# Final acceptance series

The frozen sequence is declared in FINAL_SERIES_PLAN.json. It is not inferred from game names.

RUN_FINAL_ACCEPTANCE.cmd, launch_final_series.ps1, FINAL_CANDIDATE_IDENTITY.json and the verified Candidate ZIP belong together in one folder. On a Windows standard-user session, disconnect external network access and run the CMD once. The bundled Python drives three independent fresh extractions and each starts with START_QA.cmd.

The controller keeps each full RESULT_FOR_CHATGPT.zip, target preparation evidence, independent Run/fresh IDs and a mechanical SERIES_COMPARISON.json. It removes only its own successful disposable extractions after retaining their validated evidence. A failed extraction is kept for diagnosis.

Technical PASS does not grant independent HQ approval, human review, offline certification, Product Acceptance, Stable or Release. Those states are reported separately. The helper records elevation and hosted/local provenance; it does not invent offline or human evidence.

The existing Code Geass run is historical diagnostic evidence. It is excluded from the final sequence.
