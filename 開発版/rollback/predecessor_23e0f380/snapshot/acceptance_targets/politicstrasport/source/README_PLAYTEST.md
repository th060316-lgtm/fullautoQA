# PoliticsTrasport Logic Prototype (Grok)

未検証の最小Logic Prototypeです。正式実装ではありません。

## 起動方法

1. Godot 4.x（推奨 4.2〜4.3）をインストールする。
2. 本zipを解凍する。
3. Godotで `project.godot` を開く（「Import」またはプロジェクト一覧から）。
4. F5 または再生ボタンで実行する。

## 操作方法

- **都市/補給基地クリック**: 選択。建設モード中は2点目選択で路線作成。
- **路線クリック**: 路線選択。
- **道路建設 (R / ボタン)**: 道路建設モード開始 → 2都市を順にクリック。
- **鉄道建設 (T / ボタン)**: 鉄道建設モード開始 → 2都市を順にクリック。
- **撤去 (X / ボタン)**: 選択中の路線を廃止。
- **x1 / x5**: 時間速度変更。
- **Pause**: 一時停止切替。
- **強制開戦**: テスト用に赤国 vs 青国で即開戦・補給基地出現。

## 何を確認すべきPrototypeか

コア体験の検証用です。

1. 輸送すると都市の人口・経済が目に見えて増えるか。
2. 景気変動で需要・成長が変わるか。
3. 戦争が発生し、補給基地が出現するか。
4. 補給基地へ食料/燃料を運ぶと戦争判定の補正が入り、ログに出るか。
5. 戦争終了後に都市の所属が変わり、景気や成長が変化するか。
6. 基地廃止後、基地接続路線が無効になり「一時的に儲かった路線が不要になる」体験ができるか。
7. 廃線して別地域へ投資し直す動機が生まれるか。

プレイヤーは輸送会社のままです。戦争の勝敗を直接指定するコマンドはありません。

## 10分程度の推奨試遊手順

1. 起動直後、6都市と3国家色を確認。資金500、Seed表示を確認。
2. 赤都 ↔ 赤港 に道路を建設。青都 ↔ 青鎮 に道路。緑都 ↔ 緑谷 に道路。
3. x5 にして数日進め、資金増加と都市人口微増を確認。
4. 赤都 ↔ 青都 に鉄道を建設（高額・高容量）。収益差を体感。
5. 「強制開戦」を押し、補給基地出現とログ「開戦」「基地設置」を確認。
6. いずれかの都市から補給基地へ道路または鉄道を接続。
7. 数日進め、ログに「食料/燃料補給により○○戦争補正+X」が出ることを確認。資金が戦時プレミアムで増えることも確認。
8. 戦争が終わるまで待つ（または高速）。勝利ログ、都市所属変更、基地廃止、基地路線無効化を確認。
9. 不要になった基地接続路線を撤去。別の都市間に新規投資。
10. 景気ログ（好況/不況入り）と、不況都市の需要低下を観察。

## 既知の制限

- 乗継ぎなし（直通のみ）。
- 補給基地は1戦争につき1つ、主に一方の側タグ。
- 戦術・ユニット・詳細外交なし。
- Save/Loadなし。
- 見た目は図形のみ。
- 数値は検証用の仮バランス。破綻しにくい程度にクランプ済み。
- Godotエディタ上での実行を想定。エクスポートは任意。

## Seed

画面上部にSeedが表示されます。同一Seedで初期配置と乱数系列が再現しやすくなっています（完全決定論ではない箇所もありますが、テスト比較用）。
